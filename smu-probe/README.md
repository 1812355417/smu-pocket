# smu-probe

抓包与接口逆向的临时工作区，**不参与 APK 构建**。

参考项目（`gzucm-pocket`）的做法值得照抄：每确认一个系统，就写一份接口规格 md，
把「请求 → 响应 → 字段字典 → 已知坑」固化下来。Kotlin 解析器照着规格写，
接口改版时对着规格 diff 就知道哪里变了。

## 这里面放什么

```
smu-probe/
├─ 教务接口规格.md       ← 抓完 B1/B2/B4/B5 后写
├─ 电费接口规格.md       ← 抓完 §6 后写
├─ fixtures/             ← 脱敏后的原始响应（也复制一份到 app/src/test/resources/）
│   ├─ timetable_all.json
│   ├─ timetable_week8.json
│   ├─ grades.json
│   └─ power_balance.json
└─ *.py                  ← 后续的 Playwright/CDP 探针（可选）
```

## 脱敏规则（重要）

只改值，**不改字段名、不删字段、不改结构**：

| 原值 | 换成 |
|---|---|
| 学号 | `2023000001` |
| 姓名 | `张三` |
| 密码 / Cookie / JSESSIONID / token | `<REDACTED>` |
| 楼栋房间 | `X栋XXX` |
| 身份证 / 手机 / 家庭住址 | 整条删掉 |

`fixtures/*.har` 已经在 `.gitignore` 里排除——HAR 里带着登录凭证，别提交。

## 规格 md 的模板

```markdown
# 南医大教务接口规格

## 0. 访问机制
（是否需要先登录、是否 iframe 内嵌、直接 GET 会被 302 到哪里）

## 1. 功能 → 接口对照
| 功能 | 页面路径 | 数据接口 | 实测条数 |

## 2. 课表
    POST /... 
    参数说明 + 字段字典 + 一份响应样例的路径

## 3. 成绩
## 4. 学期与校历
## 5. 已知坑
（0 值陷阱、带单位字符串、字段冗余、单双周格式……）

## 6. 移植建议
（哪些能做、哪些只跳转不做）
```
