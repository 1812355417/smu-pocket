# 南医大电费系统接口规格（只做了调研，**未接入**）

> 2026-10-30 实测。入口：`https://zwczndbcz.smu.edu.cn/cgdz/newWeixin/ele/eleInfo.html?v=1.0`
> 与教务系统同一个反代 IP（10.161.38.5）。

## 结论：无法在 App 内自动查询

`/cgdz/service/weixin/index` 直接 302 到微信 OAuth：

```
https://open.weixin.qq.com/connect/oauth2/authorize
  ?appid=wx7c3b695d169d192e
  &redirect_uri=https%3A%2F%2Fzwczndbcz.smu.edu.cn%2Fcgdz%2Fservice%2Fweixin%2FgetOpenId
  &response_type=code&scope=snsapi_base&state=123
```

- 身份是 **WeChat openid**，不是 cookie
- 访问 `eleInfo.html` **不下发任何 cookie**（已用 cookie jar 验证）
- 没有 openid 时，`/service/find/userinfo`、`/service/ammeterBalance` 都返回
  **1050 字节的 GBK HTML**，标题「抱歉，出错了」
- `snsapi_base` 的 code 只能由微信客户端生成，App 伪造不了

→ **只能做「复制链接去微信打开」**，见 `ui/power/PowerScreen.kt`。

## 页面结构

纯 jQuery + jquery-weui（`jquery-2.1.4` / `jquery-weui.js` / `layer.js`），
**没有微信 JS-SDK**（无 `jweixin` / `wx.config`），OAuth 在服务端完成。

`path = getPath()` = `/cgdz`。

## 接口清单

| 接口 | 方法 | 需要 openid | 说明 |
|---|---|---|---|
| `/service/weixin/index` | GET | — | 302 微信 OAuth |
| `/service/weixin/getOpenId` | GET | — | OAuth 回调 |
| `/service/find/userinfo` | GET | ✅ | `{realName, studentNum, loudongName, roomName, roomId}` |
| `/service/ammeterBalance?type=1` | GET | ✅ | 电表余额 |
| `/service/weixin/eleInfo` | GET | ✅ | 电费信息 |
| `/service/register` | POST | ✅ | 注册：`{name, idcard(学号), phone}` |
| `/service/room/save` | POST | ✅ | 绑定房间 |
| `/service/room/unbound` | POST | ✅ | 解绑 |
| `/service/find/deleteUser?sign=` | GET | ✅ | 注销 |
| `/service/school/list?proviceCode=1001&idCode=1001` | GET | ❌ | 学校列表（**唯一公开的接口**，140 字节 JSON） |

## 实测记录

```
GET /cgdz/service/school/list?proviceCode=1001&idCode=1001
→ 200 application/json  {"statusCode":"200","resultObject":[{"schoolId":301,"schoolName":"..."},...]}

GET /cgdz/service/find/userinfo           （无 openid）
→ 200 text/html;charset=gbk  1050 字节  <title>抱歉，出错了</title>

GET /cgdz/service/ammeterBalance?type=1   （无 openid）
→ 同上

GET /cgdz/service/weixin/index
→ 302 open.weixin.qq.com/connect/oauth2/authorize?...
```

## 以后要接，需要满足其中一个

1. 学校提供**按楼栋 + 房间查询**、且不依赖 openid 的接口
2. 微信里能拿到一个稳定的 `sign`/token，且可复用（目前没看到）
3. 校方开放数据

在满足之前，电费页只做「复制链接 → 微信打开」。

## 补充调查：慧新E校平台（yktydfw）也走不通

在 `newWeixin/index.html` 里发现了第二个入口 `https://yktydfw.smu.edu.cn/plat/shouyeUser`，
一度以为它是「非微信」的旁路。实测结论：**不通。**

| 项 | 结果 |
|---|---|
| 系统 | 慧新E校 · 移动服务平台（厂商：**新中新**） |
| 形态 | Vue SPA，`access_token` + sessionStorage，学号+密码登录 |
| 与电表服务的关系 | **不同厂商**（电表是深圳常工电子），页面里跳它的链接多半是充值付款 |
| 登录实测 | ❌ 报「您的账号已在"校园卡"程序登录，请先退出小程序」——**单点登录互踢** |
| 是否含宿舍电费 | 未能登录确认，但从厂商分工看大概率没有 |

即使用户退出小程序后能登进去，这条路也不适合做进 App：

- **单点互踢**：App 同步一次电费 → 微信校园卡小程序被踢下线 → 小程序重登 → App 又被踢。
  这是产品层面的硬伤，技术上绕不过。
- 厂商不同，它是「一卡通消费/充值」平台，不是「宿舍电表」系统。

## 最终结论

**南医大宿舍电费无法在 App 内自动查询。** 两条路都堵死：

1. 微信 H5 + WeChat openid（`zwczndbcz` / 常工电子）→ App 伪造不了 OAuth
2. 慧新E校（`yktydfw` / 新中新）→ 单点互踢 + 大概率没有电费模块

App 内只保留「复制链接 → 微信打开」的入口（`ui/power/PowerScreen.kt`）。

参考项目（广中医）能查电费，是因为它的 `ecard.gzucm.edu.cn` 是**普通网页 + cookie 会话**，
用 WebView 加载后劫持 XHR 即可。认证方式的差异决定了这套方案搬不过来 ——
不是技术水平问题。
