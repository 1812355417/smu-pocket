# 截图目录

README 里引用了下面这几张图。把对应的 PNG 放进来就会自动显示：

| 文件名 | 对应界面 | 建议内容 |
|---|---|---|
| `today.png` | 今日 | 日期标题 + 今日课程 + 明日课程 + 本周概览 + 考试安排 |
| `schedule.png` | 课表 | 第 N 周的网格，能看出多门课的配色区分 |
| `grades.png` | 成绩 | 各学期折叠状态 + 顶部四项统计 |
| `exams.png` | 考试安排 | 滚到底部的考试卡片 |
| `settings.png` | 设置 | 同步按钮 + 接入状态 |

## 建议

- 分辨率 1080 宽即可，不用裁剪状态栏
- **用演示数据截图**（登录页 → 「先用演示数据看看」），避免把真实课程、教师姓名、学号留在仓库里
- 想批量压缩可以用 https://tinypng.com
