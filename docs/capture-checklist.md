## 0. 怎么抓（Edge / Chrome，中文界面）

1. 打开浏览器 → `F12` 或 `Ctrl+Shift+I` → 切到 **「网络 / Network」** 面板
2. 勾上这三个：
   - ☑ **保留日志 / Preserve log**（不勾的话页面一跳转记录就清空了，登录流程必丢）
   - ☑ **禁用缓存 / Disable cache**
   - 过滤类型先选 **「Fetch/XHR」**；抓"页面本身"（HTML 表格/重定向）时切 **「全部 / All」**
3. **从登录页开始**，把要抓的流程完整做一遍（登录 → 课表 → 成绩 → 退出）
4. 导出：
   - 整段流程：网络面板空白处 **右键 → 「全部另存为 HAR（含内容）」**
   - 单条接口：**右键该请求 → 复制 → 「以 cURL (bash) 格式复制」**
5. 保存响应体：点开请求 → **「响应 / Response」** 标签 → 右键 **「保存全部 / Copy response」**，存成 `.json` / `.html` 文件

> **不要**直接截图贴聊天窗口给我——字段会被截断、中文会糊。**存成文件**最省事。

**⚠️ 抓包前先确认**：教务系统是否只能在校园网/VPN 下访问？电费是不是只有微信小程序里才有？如果是，先告诉我入口在哪。

## 7. 交付格式与脱敏规则

### 7-1 首选：一个文件夹
```
smu-capture/
├─ jw_login.har              （删掉别的域名，只留登录链路）
├─ jw_timetable_all.json
├─ jw_timetable_week8.json
├─ jw_grades.json
├─ jw_calendar.json
├─ power_balance.json
└─ 字段字典.md               （§B4-4 / §5 / §6 的表填好）
```
打包成 zip 给我路径就行，我直接读文件，不用你贴。

### 7-2 次选：cURL（每条接口一条，用 ``` 包起来）
```bash
curl 'https://zhjw.smu.edu.cn/xxx' \
  -H 'Cookie: JSESSIONID=<REDACTED>' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  --data-raw 'xnxqdm=202502&zc=8'
```

### 7-3 脱敏规则（**结构不能变**）

| 原值 | 换成 |
|---|---|
| 学号 `2023123456` | `2023000001` |
| 姓名 `李四` | `张三` |
| 密码 | `<REDACTED>`（或直接不传，我只关心字段名） |
| `Cookie` / `JSESSIONID` / `token` | `<REDACTED>` |
| 楼栋房间 `3栋502` | `X栋XXX` |
| 身份证 / 手机 / 住址 | 整个删掉 |

**只改值，不改字段名、不改嵌套结构、不删字段**。字段名就是我要的东西。

### 7-4 为什么非要"字段字典"
参考项目在自己仓库里专门写了三份规格 md（`教务功能接口规格.md` 等），就是为了解决"字段名看不出含义"这件事。真实例子里：
- `zf` / `zcjfs` / `zcj` 三个字段存的是**同一个总成绩**，直接用哪个都可能踩坑；
- 电费余额是 `"12.5 度"` 这种**带单位的字符串**，直接 `toDouble()` 会崩；
- 0 值陷阱：解析失败返回 0 时，如果当成"电量耗尽"去报警就是事故。

所以：**每个接口一份字段字典**，我照着写解析 + 单测，比反复猜快十倍。

## 9. 常见特殊情况

| 情况 | 怎么处理 |
|---|---|
| 只能校园网/VPN | 抓包在校园网下做；App 加"当前不在校园网"的友好提示，别报成"登录失败" |
| 有极验滑块/图形验证码 | 不做逆向，直接 WebView 全屏让用户自己过（已确认南医大是极验） |
| 密码前端加密 | 同上，不进 App 代码，省掉逆向 |
| 微信扫码登录 | WebView 里直接可用，这是方案的额外收益 |
| 接口返回 HTML 表格 | 我改用 Jsoup 解析；你把 HTML 原样存成 `.html` 给我，**别**手动复制成文本 |
| 有签名/token | 教务也可能被迫用 WebView；先告诉我，别藏着，不然会白写一版 |
| 抓不到某个接口 | 可能是 iframe 里发的；在 Network 面板把"全部/All"打开，或勾选"保留日志"重新点一遍 |
